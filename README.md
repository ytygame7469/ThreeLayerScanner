# 三层扫描系统 v2.0

## 📋 项目简介

三层扫描系统是一个A股量化分析工具，用于**个股强度扫描 → 板块聚合分析 → 主线信号生成**，帮助投资者识别市场机会和风险。

该项目经过10轮LLM深度讨论优化，集成了7因子强度模型、精确轮动检测、多窗口加权、假信号过滤和实战交易信号生成等功能。

## 🎯 核心功能

### 第一层：个股强度扫描（7因子模型）

| 因子 | 描述 | 权重（趋势/震荡） |
|------|------|------------------|
| 价格位置 | 三窗口加权(30+90+250天) | 0.20 / 0.40 |
| 趋势强度 | 均线排列(MA5/MA10/MA20/MA60) | 0.35 / 0.20 |
| 动量得分 | 近5日/10日/20日涨幅加权 | 0.25 / 0.15 |
| 量价配合 | 放量上涨/缩量下跌 | 0.10 / 0.15 |
| 涨停检测 | 90天内涨停次数 | 0.05 / 0.05 |
| ATR波动率 | 14日平均真实波幅 | 0.03 / 0.03 |
| 偏离衰减 | 偏离MA60幅度过大衰减 | 0.02 / 0.02 |

**核心特性：**
- **ADX动态权重**：根据市场趋势状态自动切换因子权重
- **高位钝化**：价格>85分位时分数自动衰减，避免追高
- **阶段涨幅限制**：90天涨幅>300%时强制限制分数
- **连板扣分**：识别妖股并降低其评分可信度

### 第二层：板块聚合分析

1. **强势股密度**：板块内个股强度>60分的占比
2. **精确轮动检测**：
   - 轮动度：涨停分散程度
   - 质量评分：综合评估轮动可信度
   - 龙头识别：判断板块是否有龙头领涨
3. **质量阈值过滤**：仅保留质量评分>0.5的真实轮动

### 第三层：主线信号生成

**三维信号：**
- 🔴 极度泡沫（恐贪>75 + 高密度）
- 🟠 高位过热 + 强势密集 → 泡沫风险
- 🟢 低位 + 强势启动 + 轮动 → 板块反转
- 🟡 低位 + 强势出现 → 关注反转
- 🔄 轮动涨停 + 强势 → 资金流入

**交易信号：**
- **S级 (STRONG_BUY)**：恐贪<40 + 密度>30% + 轮动 + 放量 → 仓位40%，止损-5%
- **A级 (BUY)**：恐贪<50 + 密度>20% + 轮动 → 仓位20%，止损-3%
- **WATCH**：低位无强势 → 观望
- **SELL/REDUCE**：高位过热 → 减仓/卖出

```python
CONFIG = {
    "windows": {"short": 30, "medium": 90, "long": 250},  # 窗口参数

    "rotation_quality_threshold": 0.5,                     # 轮动质量阈值
    ...
}
```
