## 底部轮动启动检测框架

### 1. 底部轮动vs高位轮动区分

```
区分算法:
输入: 板块指数, 个股列表
1. 计算板块相对位置 = (当前价 - 52周最低) / (52周最高 - 52周最低)
2. 计算个股均线偏离 = MA20偏离度中位数
3. 底部条件: 板块位置 < 0.3 AND 均线偏离 < -15% AND 破净率 > 30%
4. 高位条件: 板块位置 > 0.7 AND 均线偏离 > 20%
```

### 2. 地产板块特征加权

```python
地产特征因子:
- 政策事件得分: 关键词匹配(放松/降息/纾困) → 0-10分
- 超跌深度: 最大回撤 > 40% → 加权1.5
- 破净比例: PB<1的个股占比
- 负债率分层: 区分国企/民企安全边际
```

### 4. 轮动扩散判断

```python
扩散确认算法:
1. 龙头识别: 
   - 连续2日涨停的个股出现
   - 或单只个股5日涨幅 > 25%

2. 跟涨效应:
   - 板块内上涨家数占比 > 60%
   - 涨幅>3%的个股数持续增加

3. 资金持续度:
   - 北向资金连续3日净流入
   - 板块大单净流入 > 前5日均值2倍

扩散得分 = 龙头出现(0/1)*0.4 + 跟涨比例*0.3 + 资金持续度*0.3
if 扩散得分 > 0.7: 确认为板块行情启动
```

### 5. 信号等级定义

| 等级 | 条件 | 操作建议 |
|------|------|----------|
| **C级-试探** | 涨停数2-3只, 低重复, 量能温和放大 | 观察池, 仓位<5% |
| **B级-确认** | 涨停数3-5只, 出现2连板, 量比>1.5 | 试探建仓, 仓位5-10% |
| **A级-扩散** | 涨停>5只, 龙头明确, 板块涨幅>3% | 主升参与, 仓位10-20% |
| **S级-主线** | 持续3天A级, 政策+资金共振 | 重仓出击, 仓位>20% |
